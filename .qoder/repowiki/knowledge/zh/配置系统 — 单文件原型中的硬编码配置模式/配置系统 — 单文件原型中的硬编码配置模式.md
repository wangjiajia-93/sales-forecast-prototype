该仓库为纯前端高保真 HTML 原型，不包含后端服务、配置文件或环境变量加载逻辑。所有"配置"均以 JavaScript 常量形式硬编码在单个 HTML 文件中：

1. **数据定义集中存放**：页面名称映射 `PAGE_NAMES`、月份标签 `M_LABELS`、用户列表 `SCM_USERS`、各页面的表格数据（如 `excSummRows`、`ratioRows`、`regionRows`、`zoneRows`、`countryRows`、`summaryDetailRows`）均作为顶层 const 变量直接声明在 `<script>` 块中。

2. **无外部配置文件**：仓库中没有 `.env`、`.yaml`、`.toml`、`.json`、`.properties` 等任何配置文件；也没有配置加载函数或配置管理模块。

3. **无运行时配置机制**：页面切换通过 `switchPage()` 函数和 `currentPage` 变量控制，审批流程状态通过 `approvalContext` 对象维护，全部是内存中的 JavaScript 状态，不涉及持久化或远程配置。

4. **样式与行为内联**：CSS 样式直接写在 `<style>` 标签中，交互逻辑写在 `<script>` 标签中，整个应用仅由一个 HTML 文件构成。

5. **版本信息硬编码**：侧边栏底部显示 `v1.0.0 高保真原型`，版本号以字符串形式嵌入 HTML。

由于这是一个静态原型演示文件，不存在传统意义上的配置系统（如配置中心、环境变量注入、配置文件分层加载等）。所有行为和数据均由前端 JavaScript 硬编码实现，不具备运行时可配置能力。
