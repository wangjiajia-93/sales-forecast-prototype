本仓库为单文件 HTML 高保真原型，前端样式全部以内联 `<style>` 标签形式集中在 `sales-forecast-prototype.html` 中，未使用任何外部 CSS 框架、CSS-in-JS、SCSS/SASS、Tailwind 或设计令牌系统。整体风格借鉴了 Ant Design 的配色与组件语义（如主色 `#1890ff`、成功/警告/危险语义色、卡片/表格/按钮等命名），但所有样式均为手写原生 CSS。

**样式组织方式**
- 全局重置：`*{box-sizing:border-box;margin:0;padding:0}`
- 布局采用 Flexbox + Grid 混合：`.layout`（侧边栏+主内容）、`.grid-*`（2~6列栅格）、`.stack`/`.row`/`.row-between`（弹性堆叠与行）
- 深色侧边栏（`#001529`）+ 浅色主背景（`#f0f2f5`）+ 白色卡片（`#fff`）构成经典后台管理界面配色
- 字体栈优先使用系统字体（Apple System、Segoe UI、PingFang SC、Microsoft YaHei），字号以 12px/14px 为主，行高 1.5

**组件化约定**
- 卡片：`.card` + `.card-header` / `.card-body` / `.card-body-sm` / `.card-body-none`
- 统计指标：`.stat`（含 `.stat-label`、`.stat-value`、`.stat-unit`、`.stat-desc`）
- 按钮族：`.btn`、`.btn-primary`、`.btn-danger`、`.btn-sm`、`.btn-link`、`.btn-disabled`
- 表单：`.form-group` + `.form-label`（含必填标记 `.req`）+ 标准 input/select/textarea 样式
- 表格：`.table-wrap` 包裹，表头 sticky、斑马纹、右对齐数值列 `.td-right`、居中 `.td-center`
- 标签与徽章：`.tag-*`（蓝/绿/橙/红/灰）、`.pill`（圆角状态徽章）
- 弹窗：`.modal-overlay` + `.modal`（头部/主体/底部三段式）
- 分页：`.pagination` + `.page-btn`（含 active/disabled 态）
- Tab：`.tabs` + `.tab-btn`（下划线激活态）

**交互与状态视觉**
- 修改前后对比通过 `.m-before`（删除线灰色）和 `.m-after`（蓝色加粗）区分
- 审批状态通过 `statusPill()` 函数动态生成带背景色的 pill 标签
- 来源类型通过 `sourceTag()` 函数渲染不同颜色的 tag
- 图表区域统一使用 `.chart-placeholder` 占位（渐变背景 + 虚线边框）

**约束与限制**
- 无响应式断点：原型固定宽度布局（侧边栏 240px，主内容自适应），未使用媒体查询
- 无 CSS 变量：颜色值硬编码，无法通过主题切换扩展
- 无构建流程：纯静态 HTML，无需编译步骤
- 无组件库依赖：所有 UI 元素均手写实现，不引用任何第三方样式包
